## Sobre o site

- **Visual:** direção editorial e sombria, com tipografia serifada em destaque, fundo escuro, textura de grão sutil e um único tom de acento.
- **Responsivo:** layout pensado primeiro para o celular, com menu recolhível em telas pequenas.
- **Acessível:** HTML semântico, foco visível, textos alternativos nas imagens e respeito à preferência de movimento reduzido.
- **Leve:** um único arquivo HTML com CSS e JavaScript incorporados, sem frameworks nem bibliotecas.
- **Compartilhável:** metadados Open Graph para uma boa prévia do link em redes sociais e aplicativos de mensagem.

## Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/thyego17/Portif-lio.git
   ```
2. Abra a pasta e dê um duplo clique em `index.html`, ou use uma extensão como o Live Server no VS Code.

Não é necessário instalar nada.

## Como publicar

O site é publicado com o GitHub Pages:

1. No repositório, abra **Settings → Pages**.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/ (root)`, e salve.
4. Em alguns minutos o site estará no ar.

## Como personalizar

- **Cores:** altere as variáveis no início do `<style>`, dentro de `:root`.
- **Projetos:** edite os blocos `<article class="work">` em `index.html`. Cada um tem título, descrição, tecnologias, link do site, link do código e imagem.
- **Contato:** atualize os links na seção "Contato".
